# Raju Gudla — Portfolio

A responsive portfolio website for Raju Gudla, a B.Tech student and developer focused on web development, UI/UX, and creative digital work.

## Features
- Responsive single-page portfolio with anchored Home, About, Projects, Skills, and Contact sections
- Animated bar-wave hero visual inspired by the supplied Figma prototype
- Project cards with editable project links
- Skills grid, education snapshot, and contact form
- Accessible navigation, reduced-motion support, and mobile layout
- Contact form opens the visitor's email app with a prefilled message (no backend or data collection)

## Run locally
No build step or dependencies are required. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Customize
Update project URLs, email address, and social links in `index.html`. Replace the sample project cover artwork in `assets/` with your own screenshots.

## Deploy
This is a static site and can be deployed directly to GitHub Pages, Netlify, or Vercel. For GitHub Pages, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
